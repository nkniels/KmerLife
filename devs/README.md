# Dev Cards 
 
Each developer loads their own card into their AI IDE (Antigravity, Cursor, Claude Code, ...) as 
persistent context and starts every prompt with `[DEV-0X] [DOMAIN: <domain>]`. Ownership is 
enforced by `.github/CODEOWNERS`, not by trust.
